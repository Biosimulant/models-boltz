# Qualification remains incomplete

This adapter calls NVIDIA-hosted Boltz-2. It does not make hosted model weights
immutable or establish equivalence to NIM 1.9.0. The provider may change the
service. Preserve response headers and native bytes for every actual attempt.

Technical contract tests and successful inference do not establish biological
accuracy. Held-out benchmarks, uncertainty, acceptable numerical tolerances,
ligand connectivity/stereochemistry and domain coverage remain to be reviewed.
No clinical, diagnostic, therapeutic efficacy or regulated use is supported.

MSA formats other than A3M need additional client query/column validation.
Provider-side full PAE/PDE files and large-result redirects need an explicit
retrieval adapter before those capabilities can be advertised. No fabricated
matrix or metric replaces unavailable results.

Native pIC50 and affinity_pred_value remain separate. No Boltz affinity profile
is assigned before their exact semantics and cardinality have been resolved.
All compatibility additions remain proposals on the dedicated catalog branch.

The local environment secret is not automatically a Hub secret. Managed runs
must receive it through an approved server-side secret facility. Never place a
key in ordinary inputs, manifests, logs or published artifacts. No Hub run,
private release or public qualification is claimed by these source files.
